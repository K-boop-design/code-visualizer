# Code Visualizer Marketing Kit

Use this file as copy for GitHub, Gumroad, Lemon Squeezy, Ko-fi, Product Hunt, Reddit, LinkedIn, X, YouTube descriptions, and short demo videos.

## One-Line Pitch

Code Visualizer turns Python scripts and Jupyter notebooks into interactive flowcharts and ML pipeline diagrams on macOS.

## Short Description

Understand Python notebooks faster. Code Visualizer analyzes scripts and `.ipynb` files locally, then shows flowcharts, structure trees, ML pipeline stages, notebook outputs, and learning-oriented explanations in a native macOS app.

## Product Page Copy

Python notebooks are powerful, but they can be hard to read once the logic is spread across dozens of cells. Code Visualizer gives you a visual map of the code first, so you can see the flow before digging into individual lines.

Open a notebook, inspect the generated flowchart, switch to the ML pipeline view, and click any stage to see the exact code behind it. It is built for learners, Kaggle users, teachers, and developers who need to understand Python quickly.

## Feature Bullets

- Interactive Python flowcharts
- Jupyter notebook support
- Kaggle and ML pipeline detection
- Pipeline stages for loading, EDA, preprocessing, feature engineering, training, evaluation, prediction, tuning, and augmentation
- Structure tree for functions, classes, loops, branches, and expressions
- Notebook output image viewer
- Inspector panel with source code context
- Learning tab for Kaggle-style workflows
- Local-first Python analysis
- Native macOS interface

## Suggested GitHub Release Title

Code Visualizer v0.1.0 - Python and Notebook Flowcharts for macOS

## Suggested GitHub Release Notes

Code Visualizer v0.1.0 is the first public preview of the macOS app for visualizing Python scripts and Jupyter notebooks.

Highlights:

- Paste Python code or open notebooks.
- Generate interactive flowcharts.
- Detect common ML/Kaggle pipeline stages.
- Inspect code by selected node or pipeline stage.
- View notebook output images.
- Browse a structure tree of the parsed code.
- Open with a bundled sample notebook.

Known limitations:

- macOS 14+ is required.
- The app currently targets Python code and Python notebooks.
- AI explanations require the user to configure an API provider/key.
